# Kalsi Global Links

Kalsi Global Links is a Django-powered travel and consulting platform providing:

- Flight Booking
- Hotel Reservations
- Study Abroad
- Medical Tourism
- Visa Assistance

## Requirements

- Python 3.13+
- Django 6
- pip

## Installation

```bash
git clone https://github.com/bilkalsi/kalsiglobal.git
cd kalsiglobal
python -m venv .venv
```

Activate the virtual environment.

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python manage.py migrate
python manage.py runserver
```
